# 릴리즈 노트 (Release Notes)

이 문서에는 AI Vision Tracker 프로젝트의 버전별 추가, 변경, 삭제된 기능들이 타임라인 형식으로 기록됩니다.
지난 버전 기록은 지우지 않고 남겨 둡니다. 웹사이트의 **바뀐점** 탭(`website/src/changelog.js`)에도 같은 내용이 있습니다.

## [v3.0.0] - 2026-11-20
> 마우스로 물체를 지정하던 방식에서, 손 제스처로 조종하는 손 추적 전용 실행기로 바꿨습니다.
> v2.1.0 까지의 README 원본: [versions/README_v2.1.0.md](./versions/README_v2.1.0.md)

### 🚀 추가 (Added)
- **손 추적 전용 실행기 (`backend/hand_tracker.py`):** MediaPipe Hand Landmarker 로 손 관절 21개를 인식하고 손바닥 중심을 추적.
- **제스처 판별:** 주먹(FIST) = 따라가기, 손바닥(OPEN) = 정지. 3프레임 연속일 때만 전환하고, 손이 1초 넘게 사라지면 정지.
- **Mac 원격 관리 도구 `aivt` (`scripts/aivt.py`):** `run` · `preview` · `calibrate` · `deps` · `clean` · `dashboard` · `web` 을 한 줄 명령으로 실행. 실행할 때마다 라즈베리파이 코드를 자동 동기화.
- **자동 캘리브레이션:** 모터를 ±1° 움직이고 화면 이동량을 위상상관으로 측정해 °/px 게인을 저장.
- **웹 미리보기 (5001번 포트):** 손 관절, 손바닥 중심, 화면 가운데와의 오차, 추적 상태, fps 표시.
- **카메라 자동 밝기 조절:** 0.5초마다 밝기를 재서 노출(78~130)과 gain(0~40)을 조절. 번짐을 줄이려고 노출은 최대한 짧게 유지. 값을 직접 주면 고정.

### 🛠 변경 및 개선 (Changed)
- **절대 각도 명령:** "촬영 순간의 모터 위치 + 화면 오차 × 게인" 으로 손의 절대 각도를 구해 `MOVE J XY` 로 전송 (기존 `T:x:y` 방식 대체).
- **지연 보상 예측:** 0.18초 앞을 예측해 겨냥 (최대 60px).
- **모터 속도:** 최대 3000 → 3500Hz, 가속도 15 → 25Hz/ms. 연결할 때마다 `CFG` 로 전송하고 ESP32 응답으로 확인.
- **Raspberry Pi 4 용 mediapipe 0.10.18 고정:** 1.x 는 Pi 4 CPU 에 없는 명령(AES)을 써서 실행되지 않음. `aivt deps` 가 CPU 를 보고 자동 선택.
- **실측 튜닝 기본값:** 노출 130 / gain 30, `--lead 0.18`, `--max-lead-px 60`, `--acc 250` (탈조 없음 확인).

### 🐛 수정 (Fixed)
- **손을 놓칠 때 마지막 방향으로 "휙" 밀리던 문제:** 검출이 없어도 1초에 50번씩 예측 목표를 보내던 것이 원인. 새 검출이 있을 때만 명령 전송, 0.2초 놓치면 정지, 150px 넘게 튄 검출 무시, 명령 1회 이동량 제한.
- **빠르게 움직이면 손을 놓치던 문제:** 자동 노출(20~30ms)로 손이 번지던 것이 원인. 노출 시간 단축 + 자동 밝기.
- **ESP32 재시작 보호:** 실행 중 ESP32 가 재시작되면 위치 기준이 0 으로 바뀌므로 추적을 정지.
- **라즈베리파이 공간 부족:** `aivt clean` 으로 남은 공간 678MB → 4.6GB 확보.
- **`aivt dashboard` Flask 누락:** MediaPipe 와 Flask 가 함께 설치된 가상환경으로 실행.

## [v2.0.0] - 2026-07-11
> 상세 내용: [RELEASE_NOTES_v2.0.0.md](./RELEASE_NOTES_v2.0.0.md)

### 🚀 추가 (Added)
- **패키지 구조 재정비:** 평면 구조를 `config / core / hardware / web / data / scripts / tests` 역할별 패키지로 재구성.
- **복귀 보장(Escape Guarantee) 리밋 시스템:** 리밋을 벗어나는 방향만 차단하고 되돌아오는 방향은 절대 차단하지 않는 설계 도입. 사용자 리밋 병합이 붕괴되면 하드웨어 한계로 자동 복귀.
- **새 작동 범위:** M2(수직) ±45°, M1(수평) 기본 360° — 카메라가 -25° 아래를 볼 때 160°로 자동 제한.

### 🛠 변경 및 개선 (Changed & Fixed)
- **리밋 탈출 불가 버그 수정:** 사용자 리밋 병합의 부호 처리 오류로 범위가 붕괴(min ≥ max)되면 양방향이 동시에 차단되던 문제 해결.
- **프론트엔드 ES 모듈 분리:** 2,716줄 `script.js`를 17개 모듈로 분리. 존재하지 않는 UI 요소 참조로 후반부 초기화 전체(갤러리·모터상태·카메라설정·펌웨어업로드 등)가 실행되지 않던 잠재 크래시 수정.
- **자동 추적 중심 좌표 수정:** `320×240` 하드코딩을 실제 프레임 크기 기준으로 변경 (해상도 변경 시 조준 어긋남 해결).
- **보안:** 갤러리 삭제 API의 경로 탐색(Path Traversal) 취약점 수정 (`safe_join` 적용).
- **문서 현행화:** README를 실제 YOLO INT8 파이프라인 기준으로 갱신, 작동 범위/안전 리밋 섹션 신설.
- **랜딩 페이지 개편:** 다크 테마 3D 패널, 스펙 스트립, CAD 도면, 발표용 쉬운 용어(1축 수평/2축 수직) 적용.

## [v1.3.0] - 2026-07-03
### 🚀 추가 (Added)
- **라즈베리파이(Raspberry Pi) 전용 환경 구축:** 윈도우 의존성을 벗어나 라즈베리파이 터미널(Headless CLI) 환경에서 완벽하게 구동되는 `raspi_main` 독립 패키지 신설.
- **자동화 스크립트 3종:** 복잡한 명령어 없이 한 번에 구동 가능한 `install.sh`, `start.sh`, `update.sh` 추가.
- **CLI 로딩 애니메이션:** 터미널 부팅 시 `rich` 라이브러리를 활용한 직관적이고 세련된 핑크색 도트 스피너(`cli_ui.py`) 추가.
- **프로덕션 서버 연동:** Flask 기본 개발 서버 대신, 접속 안정성이 뛰어난 `waitress` WSGI 서버를 라즈베리파이 환경에 자동 연동.

### 🛠 변경 및 개선 (Changed & Fixed)
- **Linux(V4L2) 카메라 프레임 최적화:** 라즈베리파이에서 고해상도(1080p) 고프레임(30fps) 송출을 위해 `cv2.CAP_V4L2` 캡처 백엔드에 `MJPG` 코덱 강제 할당 로직 추가 (`camera.py`).
- **중복 리소스 싹둑 정리:** 이전 버전에서 발생한 쓸모없는 백업 파일들 및 외부 압축 해제 찌꺼기 중복 폴더 완전히 청소.

## [v1.2.0] - 2026-07-02
### 🚀 추가 (Added)
- **Apple Design System 적용:** 불필요한 그림자와 입체감을 모두 제거하고, 단일 포인트 컬러(Action Blue)를 사용한 극도의 미니멀리즘 플랫(Flat) UI로 전면 개편.
- **펌웨어 버전 불일치 강제 차단(Hard Crash):** 연결된 ESP32 펌웨어가 파이썬 백엔드가 기대하는 버전(2.0.7)과 다를 경우, 단순 경고를 넘어 파이썬 프로세스를 즉시 종료(os._exit(1))하여 예기치 않은 하드웨어 오작동을 원천 차단.

### 🛠 변경 및 개선 (Changed & Fixed)
- **조이스틱 뚝뚝 끊김(Stuttering) 현상 완벽 해결:**
  - 웹 조이스틱의 HTTP 갱신 주기를 20ms에서 80ms로 늦추고 불안정한 패킷 취소(Abort) 로직을 제거하여 통신 안정성 확보.
  - ESP32 펌웨어의 조그(JOG) 안전 정지(Watchdog) 타이머를 150ms에서 350ms로 늘려 무선 지연(Jitter)으로 인한 급정거 현상 방지.

## [v1.0.0] - Initial Release
### 🚀 추가 (Added)
- **AI 추적 코어:** OpenCV CSRT Tracker, Competitive Tracking (전역 템플릿 매칭), Kalman Filter 융합 다중 추적 알고리즘 탑재.
- **ESP32 모터 제어 펌웨어:** FreeRTOS 듀얼코어 기반 타이머 인터럽트(10ms 주기) P-Control 스텝모터 가속도 제어.
- **Glassmorphic Web UI:** PC 및 모바일 반응형 웹 인터페이스, 실시간 MJPEG 비디오 스트리밍 출력 기능.
- **동적 파라미터 제어:** 웹 브라우저에서 실시간으로 스테퍼 모터의 최대 속도, 가속도, steps/px 값을 설정하여 보드로 동기화.
